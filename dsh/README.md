# alibaba-cloud-cli — DeepSeek Harness

This package exposes the repository skills to DeepSeek Harness. The CLI is a separate local prerequisite; follow the setup skill before using it.

Install the plugin from the Full AIGC/Full Stack DSH market or from this repository at the repository root.

The package reads `skills/*/SKILL.md` from the same repository at runtime. It registers no MCP server because this plugin has none.
